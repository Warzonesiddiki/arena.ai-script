# Section 024: Agent Tool Tracker — Step 3: Product Brief

## Vision
Per-type tool-call counters, driven by the `agent:toolTracked` event.

## Target User
Power users running Arena.ai Agent Mode sessions who want visibility into, and control over,
what the agent is doing without leaving the page.

## Value Proposition
Part of the broader Arena Agent Mode Pro toolset — this section contributes one focused
capability (`AgentToolTracker`) to that toolset rather than standing alone as a separate product.
