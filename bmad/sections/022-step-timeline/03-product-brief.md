# Section 022: Agent Step Timeline — Step 3: Product Brief

## Vision
Rolling timeline of the last 50 tool calls/responses with timestamps.

## Target User
Power users running Arena.ai Agent Mode sessions who want visibility into, and control over,
what the agent is doing without leaving the page.

## Value Proposition
Part of the broader Arena Agent Mode Pro toolset — this section contributes one focused
capability (`ToolTimeline`) to that toolset rather than standing alone as a separate product.
