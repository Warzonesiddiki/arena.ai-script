# Section 013: Session Summary Modal — Step 3: Product Brief

## Vision
On-demand modal summarizing the current session: turns, tool-type breakdown, duration, efficiency score.

## Target User
Power users running Arena.ai Agent Mode sessions who want visibility into, and control over,
what the agent is doing without leaving the page.

## Value Proposition
Part of the broader Arena Agent Mode Pro toolset — this section contributes one focused
capability (`AgentToolbar.generateSessionSummary`) to that toolset rather than standing alone as a separate product.
