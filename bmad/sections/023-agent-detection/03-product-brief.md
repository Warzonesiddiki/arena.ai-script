# Section 023: Agent Mode Detection — Step 3: Product Brief

## Vision
Multi-strategy (URL + document title + DOM class/attribute) detection of whether the page is currently in Arena's Agent Mode; drives session start and the 'agent:activated'/'agent:deactivated' events.

## Target User
Power users running Arena.ai Agent Mode sessions who want visibility into, and control over,
what the agent is doing without leaving the page.

## Value Proposition
Part of the broader Arena Agent Mode Pro toolset — this section contributes one focused
capability (`DOMObserver.detectAgentMode`) to that toolset rather than standing alone as a separate product.
