# Section 015: Floating Elements (TOC + HUD) — Step 3: Product Brief

## Vision
Shared floating-panel behavior for draggable/persistent overlay widgets: the table-of-contents sidebar and the HUD.

## Target User
Power users running Arena.ai Agent Mode sessions who want visibility into, and control over,
what the agent is doing without leaving the page.

## Value Proposition
Part of the broader Arena Agent Mode Pro toolset — this section contributes one focused
capability (`FloatingTOC, HUD`) to that toolset rather than standing alone as a separate product.
