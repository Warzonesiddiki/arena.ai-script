# Section 012: Quick Actions Bar — Step 3: Product Brief

## Vision
Floating pill-shaped action bar with shortcuts to Settings, Export, Search, Scorecard, Context, and Clipboard actions, shown contextually during agent sessions.

## Target User
Power users running Arena.ai Agent Mode sessions who want visibility into, and control over,
what the agent is doing without leaving the page.

## Value Proposition
Part of the broader Arena Agent Mode Pro toolset — this section contributes one focused
capability (`QuickActionsBar`) to that toolset rather than standing alone as a separate product.
