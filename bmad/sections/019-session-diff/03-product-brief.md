# Section 019: Session Diff & Comparison — Step 3: Product Brief

## Vision
Side-by-side comparison of two saved (or live) sessions: turns/tool calls/errors/duration/token deltas, message-set diffing, and simple regression detection (more errors in B than A).

## Target User
Power users running Arena.ai Agent Mode sessions who want visibility into, and control over,
what the agent is doing without leaving the page.

## Value Proposition
Part of the broader Arena Agent Mode Pro toolset — this section contributes one focused
capability (`SessionDiff`) to that toolset rather than standing alone as a separate product.
